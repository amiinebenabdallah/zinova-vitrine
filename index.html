Sécurité et confiance

Vos données restent les vôtres

La sécurité est construite dans chaque écran et dans la base de données, pas ajoutée après coup.

Une société, un espace isolé

Double protection, dans l'application et dans la base : une erreur donne un résultat vide, jamais les données d'une autre société.

Chacun voit son travail

Les droits suivent le rôle. Une animatrice ne voit ni chiffre d'affaires ni les résultats de ses collègues.

Double authentification

Code à usage unique pour la direction. Seul Zinova crée les comptes, chacun choisit son mot de passe.

Photos supprimées

La photo de check-in est effacée dès la décision du responsable. La trace de la décision est conservée.

Chaque action tracée

Les actions sensibles sont enregistrées dans un journal d'audit séparé, qui ne peut être ni modifié ni effacé.

Aucun traceur

Ni publicité ni outil de mesure externe. Les polices et les fichiers sont servis par nos serveurs.
